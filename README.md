# Chama Aí! - Landing Page

Uma landing page comercial para um aplicativo que conecta freelancers para serviços ocasionais com pessoas que precisam contratar esses serviços.

## 🎨 Design

O site foi desenvolvido com as cores especificadas:
- **Azul Escuro**: #3C4E69 (cor principal)
- **Azul**: #8BA4D5 (cor secundária)
- **Off White**: #FFF7EE (fundo)
- **Laranja**: #FF9A69 (destaque/CTA)

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **TailwindCSS** - Framework CSS via CDN
- **JavaScript Vanilla** - Interatividade
- **CSS Customizado** - Animações e efeitos especiais

## 📁 Estrutura do Projeto

chama-ai-landing-page/

## 🔧 Funcionalidades

### Seções da Landing Page:
1. **Hero Section** - Apresentação principal com CTAs
2. **Features Section** - 6 recursos principais do app
3. **About Section** - Informações sobre a empresa
4. **CTA Section** - Chamada para ação final
5. **Footer** - Links e informações de contato

### Funcionalidades JavaScript:
- Menu mobile responsivo
- Navegação suave entre seções
- Efeitos de scroll no navbar
- Animações de entrada
- Sistema de notificações
- Validação de formulários
- Efeitos de hover e interação

### Recursos de Acessibilidade:
- Navegação por teclado
- Indicadores de foco
- Estrutura semântica HTML
- Contraste adequado de cores

## 🖥️ Como Executar Localmente

1. Navegue até o diretório do projeto:
   ```bash
   cd chama-ai-landing-page
   ```

2. Inicie um servidor HTTP local:
   ```bash
   python3 -m http.server 8000
   ```

3. Abra o navegador e acesse:
   ```
   http://localhost:8000
   ```
